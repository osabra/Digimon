# Modelos Digimon (.glb)

Esta carpeta contiene los modelos 3D que carga la aplicación.

Nombres esperados:
- `Gabumon.glb`
- `Agumon.glb`
- `Patamon.glb`
- `Gatomon.glb`
- `Tentomon.glb`
- `Gomamon.glb`
- `Palmon.glb`
- `Biyomon.glb`
- `Veemon.glb`
- `Wormmon.glb`
- `Guilmon.glb`
- `Renamon.glb`

El cargador admite GLB 2.0 con mallas, normales, UV y texturas embebidas. Si un modelo todavía no está disponible, la app utiliza automáticamente el modelo procedural actual como respaldo.

Los modelos deben ser archivos `.glb` que tengas derecho a distribuir dentro de la aplicación.
