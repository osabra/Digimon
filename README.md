# Gabumon Companion 🐺

Compañero digital para Android. Primera versión del proyecto preparada para evolucionar hacia un compañero 3D/4D interactivo.

## Primera versión
- Interfaz de compañero animado.
- Estados de ánimo y nivel de cariño.
- Interacciones: saludar, acariciar, jugar y dormir.
- GitHub Actions genera automáticamente el APK de prueba.

## Próximas fases
1. Modelo 3D de Gabumon y animaciones.
2. Voz bidireccional.
3. Personalidad e IA conversacional.
4. Memoria del compañero.
5. Evoluciones, entrenamiento y minijuegos.
6. Modo compañero persistente/notificaciones.

El APK de prueba se publica como artefacto de GitHub Actions tras cada compilación.
